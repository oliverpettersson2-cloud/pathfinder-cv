# Pilot-erbjudande till Arbetsmarknadsförvaltningen, Helsingborg

**CVmatchen — AI-driven jobb- och CV-plattform för deltagare i ekonomiskt bistånd och aktivitetskrav.**

PathfinderAI (enskild firma) · oliver@cvmatchen.se · www.cvmatchen.com

---

## Sammanfattning

Vi föreslår en avgränsad pilot där en utvald enhet inom AMF får tillgång till
hela CVmatchen-plattformen under tre månader. Syftet är att utvärdera nytta,
användarvänlighet och passform mot er befintliga handläggning. Efter pilot
för vi en gemensam diskussion om fortsatt samarbete och form för
direktupphandling.

## Villkor

| | |
|---|---|
| **Period** | 3 månader (90 dagar) från startdatum |
| **Pris** | 5 000 kr/månad — totalt 15 000 kr för hela pilotperioden |
| **Antal användare** | Obegränsat antal deltagare och handläggare inom pilotenheten |
| **Support** | Direktkontakt med grundaren under hela pilotperioden |
| **Personuppgifter** | Personuppgiftsbiträdesavtal (PuB) tecknas inför start |
| **Efter pilot** | Gemensam utvärdering och dialog om eventuell fortsättning |

## Vad ingår

- Deltagar-vyn: CV-bygge, jobbmatchning, intervjuträning, 105 träningsmoduler kring arbete, studier, ekonomi, hälsa, digital kompetens och introduktion till svenska arbetslivet.
- Handläggar-vyn: deltagar-överblick per enhet, uppgift-tilldelning, statistik, CV-nedladdning som PDF, realtidsuppdatering när deltagaren slutför uppgifter.
- AI-funktioner via Claude på AWS Bedrock i Frankfurt — för förslag, översättning, intervjusimulering och CV-matchning mot jobbannonser.
- Onboarding av era handläggare (cirka 30 minuter per handläggare).

## Dataresidens och GDPR

All databehandling sker inom EU/EES:

| Komponent | Region |
|---|---|
| Webbserver (Vercel) | Stockholm |
| Databas (Supabase Postgres) | Frankfurt / Irland |
| AI (Claude via AWS Bedrock) | Frankfurt |
| E-postutskick (Resend) | EU |
| Inloggning (Microsoft EntraID) | EU |

Ingen tredjelandsöverföring. Zero data retention via Bedrock — er data
används inte för modellträning. GDPR-radering inbyggd. Mer detaljer i
separat säkerhetsdokument.
